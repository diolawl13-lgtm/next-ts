Onde acho a API Key?
  1. Abra o TeamSpeak 3 e entre no servidor da guild.
  2. Menu Ferramentas → Opções.
  3. Clique em Addons e procure ClientQuery (aba Plugins). Ele precisa estar ativado.
  4. Clique em Configurações do ClientQuery e copie a API Key.
  5. Cole aqui e clique em Conectar.
